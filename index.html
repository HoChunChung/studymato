番茄鐘陪你專注，雨聲陪你休息

番書茄 Studymato 是一個從台灣出發的 YouTube 頻道：番茄鐘計時的讀書與工作音樂、雨夜咖啡館爵士、睡前鋼琴。每支影片都有清楚的專注和休息節奏，換段時，番茄形狀的計時器「番茄仔 Mato」會叮一聲提醒你。

Studymato is a YouTube channel from Taiwan with Pomodoro study and work music, rainy café jazz and sleep piano. Mato, a tomato-shaped kitchen timer, chimes when it is time to switch between focus and rest.

前往 YouTube 頻道 → youtube.com/@studymato

Studymato Uploader

Studymato Uploader 是頻道擁有者在自己電腦上使用的工具，透過 YouTube API Services 把番書茄 Studymato 的影片上傳到自己的頻道、設定排程公開、縮圖、播放清單和多語標題，並讀取自己頻道的觀看數據來產生週報。

這個工具不對外提供，也不會存取其他人的 YouTube 帳號或資料。

Studymato Uploader is a private tool run by the channel owner on their own computer. It uses YouTube API Services to upload videos to the owner's own channel, schedule publishing, set thumbnails, playlists and localized titles, and read the owner's own channel analytics for weekly reports. It is not offered to the public and does not access anyone else's YouTube account or data.
