隱私權政策

生效日期：2026 年 10 月 22 日　Effective date: October 22, 2026

本政策說明「Studymato Uploader」（以下稱「本工具」）如何處理透過 Google 帳戶授權取得的資料。本工具由 YouTube 頻道「番書茄 Studymato」的擁有者自行開發和使用，只在擁有者自己的電腦上執行，不對外提供服務。

This policy explains how "Studymato Uploader" (the "App") handles data obtained through Google account authorization. The App is built and used solely by the owner of the YouTube channel "番書茄 Studymato". It runs only on the owner's own computer and is not offered as a service to anyone else.

1. 使用 YouTube API Services

本工具使用 YouTube API Services。使用本工具即表示你同意 YouTube 服務條款，並適用 Google 隱私權政策。

The App uses YouTube API Services. By using the App you agree to be bound by the YouTube Terms of Service, and the Google Privacy Policy applies.

2. 存取哪些資料

經頻道擁有者授權後，本工具只存取該擁有者自己頻道的以下資料：

  • OAuth 存取權杖和更新權杖：用來代表擁有者呼叫 YouTube API。
  • 頻道基本資料：頻道 ID、名稱、訂閱數、影片數、是否可上傳長片。
  • 影片和播放清單：擁有者自己上傳的影片、縮圖、標題、說明、多語翻譯、排程公開時間和播放清單。
  • 頻道數據：觀看次數、觀看時數、訂閱增減、按讚和留言數（YouTube Analytics API）。

本工具不讀取觀眾的個人資料、不讀取留言內容，也不存取任何其他人的 Google 或 YouTube 帳戶。

With the channel owner's authorization, the App accesses only the owner's own channel: OAuth access and refresh tokens; basic channel information (ID, title, subscriber and video counts, long-upload eligibility); the owner's own videos, thumbnails, titles, descriptions, localizations, scheduled publish times and playlists; and channel analytics (views, watch time, subscriber changes, like and comment counts). The App does not read viewers' personal data or comment text, and does not access any other person's Google or YouTube account.

3. 如何使用這些資料

  • 把擁有者製作的影片上傳到擁有者自己的頻道，並設定排程公開、縮圖、播放清單和多語標題。
  • 讀取自己頻道的數據，產生只給擁有者看的週報。

Google 使用者資料只用於上述功能。本工具遵守 Google API 服務使用者資料政策，包括「有限使用」（Limited Use）規定：不出售資料、不用於廣告、不轉給第三方，也不讓任何人閱讀，除非是擁有者本人、為了安全目的，或法律要求。

Data is used only to upload the owner's videos to the owner's own channel (with scheduling, thumbnails, playlists and localized titles) and to read the owner's own analytics for private weekly reports. The App's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. Data is never sold, used for advertising, or transferred to third parties.

4. 儲存和分享

  • 權杖和數據只存在擁有者自己的電腦上：權杖檔案設定為只有擁有者的系統帳戶能讀取；數據存在本機的資料庫和 CSV 檔。
  • 本工具沒有伺服器，不把資料上傳到任何雲端服務，也不和任何人分享。
  • 本網站不使用 cookie、追蹤碼或分析工具。

Tokens and analytics are stored only on the owner's own computer (token files are readable only by the owner's system account; analytics are kept in a local database and CSV files). The App has no server, does not upload data to any cloud service and does not share data with anyone. This website uses no cookies, trackers or analytics.

5. 保存期限和刪除

  • 從 API 取得的頻道數據只在授權有效期間保存在本機，並每週重新抓取更新。
  • 擁有者撤銷授權後，會在 7 天內刪除本機儲存的權杖和從 API 取得的資料。
  • 你隨時可以到 Google 帳戶的「第三方存取權」撤銷本工具的授權。

Channel data obtained from the API is kept locally only while authorization is active and is refreshed weekly. If authorization is revoked, locally stored tokens and API data are deleted within 7 days. You can revoke the App's access at any time at Google Account › Third-party access.

6. 兒童

本工具不對外提供，也不蒐集兒童的資料。

The App is not offered to the public and does not collect data from children.

Changes to this policy will be posted on this page with an updated effective date.
